# Stack Tasks (C++)

| Folder | Task | Description |
|---|---|---|
| `Task1/` | Task 1 | Generic stack (`myStack<T>`) built on an abstract stack class: push, pop, top, isEmpty, isFull, display |
| `Task2/` | Task 2 | Stack with `getMin()` — returns the minimum element using an auxiliary min stack |
| `Task3/` | Task 3 | Car parking lot (capacity 8) using a stack — park, remove a car via a temporary stack, search, count |
| `Task4/` | Task 4 | Text editor with undo/redo implemented using two action stacks |

## Compile & run

```
g++ Task1/task1.cpp -o task1
./task1
```
